# 寶寶記憶遊戲 - 起始專案

## 怎麼打開測試

**重要：不能直接雙擊 index.html 打開！**
因為程式會用 `fetch()` 讀取 `data/` 資料夾裡的 JSON，瀏覽器基於安全性限制，
用「直接開檔案」的方式（網址列會是 `file://...`）會讀取失敗。

正確做法：
1. 在 VS Code 左側安裝「Live Server」擴充套件（左側方塊圖示 → 搜尋 Live Server → 安裝）
2. 在 VS Code 左側檔案列表裡，右鍵點 `index.html`
3. 選「Open with Live Server」
4. 瀏覽器會自動打開，網址列會是 `http://127.0.0.1:5500/...` 這種格式，這樣才是對的

## 目前能玩到什麼

- 讀取 `data/levels.json` 的第一關（親親親拍拍拍抱）
- 按方向鍵（↑↓←→）或空白鍵操作，也可以直接點畫面上的按鈕
- 按對會亮起格子+噴✨，按錯會變叉叉
- 全對 / 部分對 / 全錯 / 按 PHOTO(📷) 會在畫面上顯示對應的結局文字（之後換成正式的結局全螢幕圖）

## 檔案結構

```
index.html          ← 畫面骨架
style.css            ← 所有樣式跟配色
src/
  config.js          ← 按鍵對應、文字標籤、倒數秒數，之後要調整這些直接改這裡
  main.js             ← 主程式，只負責讀資料+把模組串起來，保持乾淨
  core/
    SequenceGame.js   ← 核心邏輯：序列比對、計時、答對/答錯判定
    IconPanel.js       ← 四角裝飾icon（含隱藏的PHOTO彩蛋）
    BabyAnimator.js    ← 寶寶圖片+動畫狀態切換
data/
  levels.json         ← 關卡序列（未來 Excel→JSON 轉出來的檔案取代這個）
  icons.json          ← 四角icon設定，哪個是真的（isReal）在這裡改
  baby-states.json    ← 寶寶各狀態對應的圖片跟動畫效果
assets/
  baby/               ← 寶寶圖片（目前是佔位圖，換成正式美術時直接覆蓋同檔名即可）
```
